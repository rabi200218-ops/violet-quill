원고 쓰기

한 줄이 한 문단. 웹소설 원고 규칙대로 씁니다

엔터 한 번이면 다음 문단입니다. 문단 사이 간격과 첫 줄 들여쓰기는 화면에만 보이고, 본문은 깨끗한 텍스트로 저장돼요. 연재처에 올릴 때는 그 연재처 규칙대로 바꿔서 복사합니다.

연재처 기준 글자 수와 연재용 복사

작품마다 연재처를 고르면 글자 수 세는 방식(공백 포함·제외, 바이트)과 목표 분량이 맞춰져요. 위쪽 막대가 목표까지 얼마나 남았는지 보여 줍니다.

3,128자/ 5,000자 · 공백 포함 · 노벨피아 기준
  • 연재용 복사작가 메모·주석 줄은 빼고, 연재처 규칙(빈 줄, 들여쓰기, 따옴표)대로 바꿔 클립보드에 담아요.
  • 문단 간격 · 줄 간격 · 들여쓰기 · 글꼴 · 자간화면 모양만 바뀌고 본문 텍스트는 그대로예요.
  • 회차 옆 분량 표시글자 수, 공백 제외, KB(한글 2바이트·UTF-8) 중에서 고를 수 있어요.

쓰는 손을 멈추지 않게 하는 입력 도우미

한글 입력 중에도 자연스럽게 동작하도록 만들었어요.

  • 따옴표·괄호 짝 맞추기“ ” ‘ ’ 「 」 『 』 ( ) 를 자동으로 닫고, 닫는 기호 앞에서 엔터를 치면 기호는 그대로 두고 다음 문단으로 넘어가요.
  • 사용자 대치어... → …, [[ → 「 처럼 내가 정한 규칙으로 바꿔요. 정규식도 돼요.
  • 구분선 · 주석 줄***는 정해 둔 구분선으로, //로 시작하는 줄은 나만 보는 메모가 되어 복사·내보내기에서 빠져요.
  • AI 없는 맞춤법 검사몇일→며칠, 금새→금세, 할께→할게 같은 자주 틀리는 표현과 띄어쓰기를 규칙으로 잡아요. 원고가 밖으로 나가지 않아요.
  • 집중 모드 · 타자기 모드 · 모바일 폭 미리보기 · 타자 소리

원고 옆에서 플롯을 보면서 쓰는 모습. 지금 회차가 이어진 칸이 강조돼요.

초안과 확정안, 한 회차에 두 편

지금 글을 초안으로 남겨 두고 확정안을 새로 쓰거나 고쳐 써요. 초안만 보기 · 확정안만 보기 · 비교하기를 버튼으로 바꿉니다.

  • 비교하기양쪽을 나란히 놓고 바뀐 문단은 노랑, 추가는 초록, 삭제는 빨강으로 표시해요. 스크롤도 같이 움직여요.
  • 확정안 OK누르면 확정안이 메인으로 남고 초안은 숨겨져요. 회차 목록에 ✓확정이 붙어요.
  • 스냅샷고치기 전 원본을 회차마다 30개까지 보관해 언제든 되돌려요.
캐릭터 · 세계관 · 타임라인

설정은 한곳에, 본문과 자동으로 연결

캐릭터와 설정집에 등록한 이름이 본문에 나오면 알아서 찾아 줘요. 커서를 이름 위에 두면 그 캐릭터 카드가 옆에 뜹니다.

캐릭터 카드와 관계

  • 항목 틀나이·외형·성격·말투 같은 항목을 틀로 만들어 두고 캐릭터마다 채워요.
  • 방향이 있는 관계엄마 → 딸, 딸 → 엄마처럼 서로 다르게 적어요.
  • 숨겨진 설정정체·과거·반전을 숨김 / 떡밥 뿌림 / 공개됨으로 관리해요. 평소엔 가려 둘 수 있어요.
  • 능력치·스킬 (판타지용)필요할 때만 켜고, 회차별 변화가 기록돼 그래프로 봐요.

작중 시간 타임라인

시점 칸(예: 812년 봄)과 트랙(메인 스토리, 과거 회상, 악역 측)으로 사건을 배치해요. 카드를 끌어서 옮기고, 끝을 끌어서 기간을 늘려요.

  • 캐릭터·그룹 필터한 인물의 동선만 골라 볼 수 있어요.
  • 회차순 보기사건이 몇 화에 나오는지 순서대로 봐요.
  • 시점 칸 메모칸 번호 옆에 "입학식", "축제 주간"처럼 그때가 언제인지 적어 둬요.

캐릭터 그룹 · 설정집 · 아이디어 노트

  • 그룹 안의 그룹제국 → 황실·기사단처럼 세력을 계층으로 묶고, 그룹 안 역할(단장, 내통자)을 적어요.
  • 설정집장소·아이템·용어를 분류별로. 다른 이름(별칭)도 본문에서 찾아 줘요.
  • 아이디어 노트떠오름 → 고민 중 → 써볼까! 단계로 아이디어를 굴리고, 로그라인·장르·플롯까지 정리해 바로 작품으로 시작해요.
제미나이 도우미 · 원할 때만

설정이 어긋난 곳을 찾아 주고, 플롯으로 타임라인을 잡아 줘요

내 제미나이 API 키를 넣으면 쓸 수 있어요. 버튼을 누를 때만 보내고, 보내기 전에 예상 토큰과 비용(원)을 먼저 보여 줍니다. 키는 내 PC에만 암호화해서 저장돼요.

설정 충돌 검사

이 회차 본문을 캐릭터·관계·소속·능력치·설정집·타임라인·기획·앞 회차와 비교해 어긋나는 곳만 골라요. 문장 다듬기나 재미 평가는 하지 않아요.

  • 인용문을 누르면 그 문장으로 이동의도한 거라면 "무시"로 넘겨요.
  • 숨겨진 설정 포함 선택복선이 너무 드러났는지도 봐 줘요.
  • 회차 한 번에 몇십 원 수준보통 이 회차에 나온 항목만 보내서 토큰을 아껴요.

플롯으로 타임라인 초안

기승전결·5단 구성·웹소설 초반 같은 틀로 플롯을 적어 두면, 그 플롯을 보고 시점 칸·트랙·사건을 짜 줘요.

  • 먼저 보여 주고, 고른 것만 넣어요사건마다 체크해서 필요한 것만 타임라인에 들어가요.
  • 캐릭터 자동 연결사건에 나온 인물이 캐릭터 카드와 이어져요.
  • 컨셉 이미지캐릭터·장소 컨셉 이미지도 제미나이로 만들 수 있어요.
테마

오래 앉아 있는 화면이니까, 내 취향대로

UI 디자인 7종(클래식 · 말랑 · 슬림 · 글래스 · 다이어리 · 팝 · 네온)과 색 테마 13종을 마음대로 섞어요. 우주 색감 6종은 귀여운 달·별·행성 배경이 낮/밤 따로 따라와요. 내 사진을 배경으로 써도 돼요.

내보내기와 동기화

  • 소설 내보내기TXT(회차마다 파일 따로) · 워드(DOCX) · 한글(HWPX, 한글 2014 이상) · PDF. 회차 골라서, 용지·글꼴·쪽 번호까지.
  • 작품 통째로 저장 (.vquill)원고·스냅샷·캐릭터·타임라인·설정집·이미지·기획을 파일 하나로 백업하고 다른 PC에서 불러와요.
  • 구글 드라이브 동기화로그인하면 내 구글 드라이브의 앱 전용 숨김 폴더에 자동 백업되고, 다른 PC에서 이어 써요.
설치

받아서 두 번 누르면 끝

설치 파일 하나로 끝나요. 한 번 설치하면 새 버전이 나올 때 프로그램이 알려 주고, 누르면 알아서 바뀝니다.

  1. 설치 파일 받기

    위의 다운로드를 누르고 VioletQuill-Setup-버전.exe를 받아요. 다른 파일은 받지 않아도 돼요.

  2. “PC 보호” 창이 뜨면

    코드 서명 인증서가 없어서 나오는 Windows 기본 경고예요. 추가 정보 → 실행을 눌러요.

  3. 설치 위치 고르고 설치

    그대로 다음만 눌러도 돼요. 바탕화면에 바로가기가 생겨요.

  4. 예시 작품으로 둘러보기

    첫 화면의 예시 작품 둘러보기로 기능을 먼저 만져 보세요. 지워도 괜찮아요.

업데이트: 새 버전이 나오면 프로그램 오른쪽 아래에 알림이 떠요. 업데이트 받기 → 지금 다시 시작을 누르면 끝이고, 작품과 설정은 그대로 남아요. 직접 확인하려면 오른쪽 위 ? → 업데이트 확인.

구글 드라이브 연결 (선택)

여러 PC에서 쓰거나 자동 백업을 원할 때만 하면 돼요. 프로그램 오른쪽 위 ? → 구글 드라이브 연결 방법에 화면별 단계 안내가 있어요. 처음 한 번, 10분 정도 걸려요.

저장 위치는 내 구글 드라이브의 앱 전용 숨김 폴더라서 드라이브의 다른 파일은 보지도 건드리지도 않아요.

제미나이 연결 (선택)

설정 검사·타임라인 초안·컨셉 이미지를 쓸 때만 필요해요. 구글 AI 스튜디오에서 API 키를 만들어 넣으면 되고, ? → 제미나이 연결 방법에 단계 안내가 있어요.

비용은 내 구글 계정으로 나가요. 쓰기 전에 예상 비용이 먼저 보이고, 무료 등급 키는 하루 한도가 있어요.

자주 묻는 질문

궁금한 것들

정말 무료인가요?

네. 광고도, 회원가입도 없어요. 제미나이 기능만 내 API 키로 쓰는 만큼 구글에 비용이 나가요(선택).

원고는 어디에 저장되나요?

내 PC에 저장돼요. 인터넷이 없어도 쓰고 저장할 수 있어요. 구글 드라이브를 연결하면 내 드라이브의 앱 전용 폴더에도 백업돼요. 다른 곳(개발자 서버 등)으로는 보내지 않아요.

맥이나 모바일에서도 되나요?

지금은 Windows 10·11(64비트)용만 있어요.

설치할 때 “Windows의 PC 보호” 경고가 떠요.

유료 코드 서명 인증서를 쓰지 않은 프로그램이면 나오는 경고예요. 추가 정보 → 실행을 누르면 설치돼요.

업데이트하면 작품이 사라지지 않나요?

사라지지 않아요. 작품과 설정은 프로그램과 따로 저장돼서 업데이트나 다시 설치해도 그대로예요. 그래도 중요한 작품은 가끔 작품 통째로 저장(.vquill)으로 백업해 두면 좋아요.

다른 집필 프로그램에서 쓰던 원고를 옮길 수 있나요?

본문은 그대로 붙여 넣으면 돼요. 한 줄이 한 문단이라 대부분 그대로 맞고, 문단 사이 빈 줄은 메뉴에서 한 번에 빼거나 넣을 수 있어요.

제미나이 검사에 원고가 쓰이나요?

버튼을 누를 때만 그 회차와 관련 설정이 구글로 보내져요. 결제가 연결된 유료 등급 키는 구글이 학습에 쓰지 않지만, 무료 등급 키로 보낸 내용은 서비스 개선에 쓰일 수 있어요. 연재 전 원고라면 유료 등급 키를 권해요.

삭제는 어떻게 하나요?

Windows 설정 → 앱 → 설치된 앱에서 Violet Quill을 제거하면 돼요.
